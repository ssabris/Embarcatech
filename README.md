# 🤖 Embarcatech IFMA: Sistemas Embarcados
Projetos desenvolvidos no Curso TIC EmbarcaTech, utilizando linguagem C, placa estudo BitDogLab e simulador online Wokwi.

## ⚙️ Tecnologias e Ferramentas

Os projetos são desenvolvidos utilizando os seguintes recursos:
* **Linguagem de Programação:** C
* **Hardware de Estudo:** Placa **BitDogLab**
* **Simulação:** Simulador online **Wokwi**
* **Ambiente de Desenvolvimento (IDE):** VS Code

## 🛠️ Lista de Projetos

| Projeto | Descrição |
| :--- | :--- |
| **01 - Controle Led Com Botão** | Fundamentos de GPIO: Configuração de entrada e saída, e tratamento (*debouncing*) de botões. |
| **02 - Controle de LED com dois botões** | Gerenciamento de múltiplas entradas digitais para controle de um atuador. |
| **03 - Controle 3 LEDs RGB módulo PWM Intercalado** | Introdução ao **PWM** para controle de cores e brilho (atuadores analógicos). |
| **04 - Cofre Digital 2 LEDs 4 Displays** | Controle de Displays de 7 Segmentos e técnica de multiplexação. |
| **05 - Conversor Sinais Analógicos Joystick** | Uso do **ADC** (Conversor Analógico-Digital) para leitura de sinais contínuos (Joystick). |
| **06 - Display LED 16x2\_I2C** | Protocolo de comunicação **I²C** para interação com displays e periféricos. |
| **07 - Sensor Conversor Celsius Fahrenheit** | Leitura de sensor (temperatura) e implementação de lógica de conversão matemática. |
| **08 - Interfaces UART0 e TX e RX** | Protocolo de comunicação serial **UART**, essencial para debugging e comunicação PC-micro. |
| **09 - Real Time Clock** | Configuração e uso de um **RTC** para gerenciamento preciso de tempo e data. |
| **10 - Pi Pico SDK Blink RGB** | Configuração de ambiente e uso de **SDK Nativo** (RP2040) para controle de hardware. |
| **11 - TecladoCofre** | Projeto de integração: Combina leitura de teclado matricial, lógica complexa e feedback em displays. |
| :--- | :--- |
